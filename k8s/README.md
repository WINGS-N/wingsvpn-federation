# Helm-чарты

| Чарт | Что ставит |
|---|---|
| `head` | башка: реестр нод, раздача профилей, подписки |
| `node` | наша нода в пуле: агент, Xray, релей |
| `probe` | зонд: меряет ноды оттуда, где сидят пользователи |

Values конкретного кластера живут отдельно от репозитория:

```
helm -n wingsvpn upgrade --install fed-head ./head -f <values-head.yaml>
```

Ноде нужен хост с модулем `wireguard` и один под на хост. Зонд ставится в сеть,
из которой ходят пользователи, а не рядом с башкой.

Образы собираются и пушатся руками - CI их не публикует.
